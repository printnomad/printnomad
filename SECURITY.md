# Security policy

BetterBridge reads and writes project files and, in some components, starts local processes or a local HTTP server. Please report vulnerabilities privately.

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting** ("Security" tab → "Report a vulnerability") on this repository. Do not open a public issue.

Include the affected component (`core`, `orca-plugin`, extension, helper), version, steps to reproduce and impact. We aim to acknowledge reports within 7 days.

## Supported versions

Only the latest release of each component receives security fixes while the project is in early development.
